# jp-shibou-riyuusyo

**版本：v1.2**

面向中国留学生的日本大学学部志望理由书辅导 skill。支持查询学校官网资料、从零访谈起草、修改现稿、压缩字数和更换目标学校，默认以中文沟通、日语撰写正文。

## v1.2 更新

- 起草前先确认实际用纸、题目和填写位置，支持独立用纸、志願票背面、局部栏位及 Web 出願项目。
- 初查官网或募集要项未找到要求或用纸时，先请学生上传需要填写的部分；没有用纸或要求代查时，再查具体填写位置。
- 按学校实际题目、分栏、字数和空间输出；五段框架及 v1.1 配比仅用于允许综合自由陈述且空间合适的情况。
- 对没有明确字限的横线／空白区域，根据可见版面、行宽、行数和字迹等估计容量区间，给出起草目标，并与官方字数规定和成稿实际字数明确区分。

## v1.1 更新

- 调整篇幅重点为「志望理由 > 志望动机 > 学习计划 > 未来进路」，首段保持简短。起草参考配比为总起 5%、动机 30%、理由 35%、计划 20%、进路 10%，并核对最终各段实际字数；学校指定格式及用户修改范围优先。
- 四年学习计划须在校方规定的对应年级明确写出在教授ゼミ中学什么、怎么学、希望提升什么能力；正文不写申请、选考或配属手续。
- 先确定全文中心轴，让经历、动机、学校选择、学习计划及进路围绕同一问题递进。
- 学校和教授资源须说明如何适配本人需求、如何利用，以及希望提升的具体能力，避免只罗列学校特点。

## 安装

在 Codex 对话中输入以下内容：

```text
$skill-installer
请从 https://github.com/toukaihaku/jp-shibou-riyuusyo 安装此 skill。
SKILL.md 位于仓库根目录，安装名称为 jp-shibou-riyuusyo。
```

安装完成后，在下一轮对话中使用 `$jp-shibou-riyuusyo` 调用。

## 使用示例

```text
$jp-shibou-riyuusyo
我想申请2027年入学的○○大学○○学部○○学科，请从零开始辅导我。
```

也可以同时提供现有草稿，并说明需要修改、压缩的范围，或新的目标学校。

有指定表格时，可上传需要填写的完整页或栏（保留题干、字数说明和书写区域），注明入学年度与选拔方式，让 skill 按各题要求起草。只有横线、没有明确字限时，会给出版面容量估计与建议起草字数；手写稿仍需按实际字迹试填。

## 环境与可选搭配

完整流程需要 Codex 能够浏览学校官网，并运行代码统计正文字数。

`humanizer-jp` 为可选的日语润色 skill：已安装时会配合使用；未安装时，本 skill 会按内置规则完成润色。

## 使用注意与声明

1. 使用前，请核对目标入学年度、对应选拔方式的募集要项、出愿材料说明及大学对生成式 AI 的规定。仅在校方允许的范围内使用本工具；对独立完成、禁止生成或改写、使用披露等要求，应逐项遵守。规定不明确时，请先向大学入试部门确认，不要将未提及 AI 理解为默认允许。语言润色也应遵循这些规定。
2. 本项目仅供资料整理与写作辅导参考，不代表任何大学或招生机构的官方意见，不保证合格或录取，也不承诺特定文书评分。录取结果由目标大学依据其选拔标准决定。
3. AI 生成或润色的内容可能存在错误、遗漏或不恰当的推断。提交前，请由申请者本人核实内容的真实性与准确性，并确保能够理解、解释自己的经历、申请动机及学习计划；不得编造经历、成绩、研究成果或教授联系记录。
4. 学校信息与申请要求请以目标年度官方原文为准。提交前，应再次核对课程、教授与ゼミ信息、题目、字数及提交格式，不要直接提交未经本人审阅的生成稿。
5. 提供个人材料时，请按需匿名化，避免上传证件号码、住址、联系方式等与写作无关的敏感信息；请勿将本人或他人未经脱敏的申请材料提交到本公开仓库。
